# 로컬 운영과 데이터 처리

[메인 README](../../README.md)

FastAPI와 Vite를 로컬에서 실행하는 개인용 PoC입니다. 서비스에는 운영용 인증이나 클라우드 배포 구성이 없습니다.

SQLite에는 등록한 공고와 지원자 자료의 텍스트 및 분석, 면접 질문과 답변 및 평가가 저장됩니다. ChromaDB는 공고 벡터를 로컬에 저장합니다. 원본 음성은 애플리케이션에 저장되지 않습니다.

분석이나 평가에 필요한 텍스트와 이미지 입력은 OpenAI API로 전달될 수 있습니다. 공개 데모에서는 합성 자료를 사용하고 API 키, 원본 이력서·포트폴리오, 개인 면접 기록과 로컬 데이터 파일을 저장소에 넣지 마세요.

매칭 및 면접 점수는 취업 연습을 위한 참고 지표입니다. 외부 공고 수집은 사이트 상태와 접근 가능 여부에 영향을 받습니다.
