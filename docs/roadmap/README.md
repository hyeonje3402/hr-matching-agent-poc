# 로드맵 제안

[메인 README](../../README.md)

백엔드 설정에 VERSION=1.0.0이 있고 프런트엔드는 0.1.0으로 표시되어 있습니다. 다음 내용은 통일된 릴리스 버전이나 확정 계획이 아닌 개발 마일스톤 제안입니다.

## 다음 마일스톤 제안 — v0.2.0: 일관된 매칭과 데이터 저장

- OpenAI/Gemini 설정을 각각 명시적인 환경 변수로 분리
- 제공자별 이력서 추출·임베딩·심층 평가 경로를 일관되게 지원하고 실패 원인을 명시
- 공고와 스크랩 결과를 영속 저장하고 중복·마감·삭제 상태 관리
- 이력서 원문 임시 저장과 삭제 정책, 개인정보 보호 흐름 추가
- 매칭 점수 근거와 키워드·경력별 설명을 개선하고 평가 데이터로 품질 검증
- 업로드·스크래퍼·매칭의 자동 테스트와 CI 구성

## 다음 후보 — v0.3.0: 운영자 도구

- 공고 수집 결과 검수와 출처별 최신성 표시
- 관리자·리크루터 권한과 사용 이력
- 배포 환경과 장애 모니터링 설정
- 후보자 데이터 내보내기·삭제·보존 기간 관리

## 현재 구현과 구분

현재 프로젝트는 PoC이며, 실시간 스크래핑과 추천은 코드에 포함되어 있지만 영구 공고 DB나 프로덕션 인증·배포가 확인되지 않습니다. 따라서 위 버전 항목은 구현 완료 기능으로 표현하지 않습니다.
