# 아키텍처와 매칭 흐름

[메인 README](../../README.md)

React는 FastAPI에 PDF·공고 자료를 전달하고 매칭, 면접, 성장 분석 결과를 표시합니다. 백엔드는 PDF 텍스트를 추출하고 OpenAI와 Pydantic으로 이력서 및 공고를 구조화합니다.

공고와 이력서를 OpenAI 임베딩으로 비교합니다. 단건 매칭은 ChromaDB 코사인 유사도 30%와 LLM 정밀 평가 70%를 결합합니다. 추천은 벡터 유사도를 사용하고, 잡코리아·사람인의 동일 공고를 연결할 수 있습니다.

LangGraph는 답변 평가, 다음 면접관 선택, 질문 생성, 종합 평가를 조율합니다. SQLite에는 사용자 등록 자료와 분석 결과, 면접 진행 상태 및 기록이 저장됩니다. ChromaDB에는 모델별 공고 벡터가 저장되며, 기본·수집 공고의 실행 중 목록은 메모리에 있습니다.
